# AMR-backup
Autonomous Mobile Robot (AGV) Navigation & SLAM System

- **Controller**: Raspberry Pi 4 Model B (Ubuntu / ROS 2 Jazzy)
- **Motor Driver**: Differential GA25 12V with encoders via Serial (80 RPM cruise / pure in-place rotation)
- **Sensor**: RPLiDAR C1 360° laser scanner
- **Software Suite**: Unified AGV Brain (`agv_unified_brain.py`), Web Control (`index_cyberpunk.html`), SLAM Calibration Tools, and automated test suite (136/136 unit tests passing).
